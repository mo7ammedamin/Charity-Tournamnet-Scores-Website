# ISoc Charity Tournament Scores Website

Live site: https://mo7ammedamin.github.io/Charity-Tournamnet-Scores-Website/

## Files

- `matches.csv` – group matches (tables update automatically)
- `knockouts.csv` – semifinals and finals
- `teams.csv` – team list per league/group (no need to edit)

## Enter a score

1. On github.com, open `matches.csv` (or `knockouts.csv`) → ✏️ pencil
2. Type both scores into the empty spots:
   ```
   2026-10-31,16:50,Football,Group,Wazi FC,2,Forest Boys,1,Football Pitch (9v9),FB 1 | 16:50 - 17:20
   ```
3. **Commit changes**, wait 1–2 min, refresh the site

## Knockouts

After the group stage, replace the placeholders in `knockouts.csv` (`League 1st`, `Group 1 - 1st`, `Winner SF 1`, …) with real team names.
